
# MoodUp 🌿

MoodUp — это современное iOS-приложение для отслеживания настроения, анализа привычек и улучшения самочувствия через простые ежедневные отметки и умные инсайты.

---

## ✨ Возможности

### 😊 Отслеживание настроения
- Фиксация настроения несколько раз в день
- Простой и приятный интерфейс
- Выбор через эмодзи

### 📊 Статистика
- Обзор за неделю
- Самое частое настроение
- Активность по дням
- Удобные карточки с метриками

### 💡 Инсайты и рекомендации
- Персональные рекомендации на основе:
  - качества сна
  - уровня энергии
- Контекстные подсказки на день

### 💤 Интеграция с Apple Health
- Импорт данных сна
- Автоматическое определение длительности сна
- Преобразование в качество сна (Great / Okay / Bad)
- Можно использовать без доступа к HealthKit

### 🔔 Уведомления
- Напоминания о логировании настроения
- Настраиваемая частота

### 👤 Профиль
- Редактируемый профиль
- Фото пользователя
- Настройки приложения (тёмная тема, уведомления)

  - Services
